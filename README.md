# Imago Dei Insurance Advisors

This is a fresh, blank Next.js project for Imago Dei Insurance Advisors.

## Project Metadata
- **Site Name:** Imago Dei Insurance Advisors
- **Description:** Christian values in a benefits plan you can trust.

## Getting Started

First, install the dependencies:

```bash
yarn install
```

Then, run the development server:

```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
